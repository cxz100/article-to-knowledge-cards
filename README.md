# make-knowledge-cards

把用户粘贴的文章或本地 Markdown/TXT 文件整理成 5–8 张简洁、可靠的知识卡片。每张卡片聚焦一个知识点，包含标题、核心知识、简明解释，以及原文例子或自测问题。原文支持的知识点不足时会少出几张，不为凑数而重复或编造。

Skill 位于 [`skills/make-knowledge-cards`](skills/make-knowledge-cards)。在 Codex 中调用 `$make-knowledge-cards`，然后粘贴文章，或提供本地 `.md`/`.txt` 文件。

## 输入与输出示例

输入：

> 检索练习是主动从记忆中提取信息，而不是再次阅读。学习者可以合上书回答问题，或用抽认卡回忆概念。检索会让人看见哪些内容还不熟。把练习分散到多天，通常比在一天内集中完成更有助于长期记忆。每次答错后查看正确答案，可以纠正理解。题目应聚焦正在学习的材料。

输出（节选）：

1. **标题：检索练习是主动回忆**  
   **核心知识：** 检索练习要求学习者主动从记忆中提取信息。  
   **简明解释：** 它不同于只重新阅读材料；学习者需要尝试自己想起内容。  
   **例子或自测问题：** 合上书回答问题属于哪种练习？
2. **标题：检索能暴露知识缺口**  
   **核心知识：** 回忆练习能显示哪些内容还不熟。  
   **简明解释：** 回答时遇到困难，可以帮助学习者发现需要继续学习的部分。  
   **例子或自测问题：** 检索练习能帮助发现什么？
3. **标题：把练习分散到多天**  
   **核心知识：** 将练习分布在多天，通常比一天内集中练习更有助于长期记忆。  
   **简明解释：** 练习安排的时间分布会影响长期记忆；原文表述的是一般倾向，而非绝对保证。  
   **例子或自测问题：** 原文认为哪种练习安排通常更有助于长期记忆？

完整输出会覆盖原文中其他独立要点；若文章只支持少于五个有价值的知识点，会说明原因并按实际数量输出。
